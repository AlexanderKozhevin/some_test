# edge_center — пространство для роста

Концепция лендинга, визуальной системы и интро.

- [Открыть сайт](https://alexanderkozhevin.github.io/some_test/)
- [Брендбук · PDF, 18 страниц](https://alexanderkozhevin.github.io/some_test/downloads/edge-center-brandbook.pdf)
- [Интро · MP4, 30 секунд](https://alexanderkozhevin.github.io/some_test/assets/edge-center-intro.mp4)

Статический HTML/CSS/JavaScript. Локальный запуск: `python3 -m http.server 4317`.

Видео: HyperFrames 0.8.31, изображения GPT Image 2.5 Flare, движение MiniMax H3 Max Turbo, музыка Lyria 2. Вывод 1920×1080 / 30 fps / H.264 + AAC.

Это дизайн-концепт. Форма создаёт предпросмотр письма и использует mailto; backend отсутствует. Golos Text временно заменяет гарнитуру Edge. Лицензии на Golos и Lucide находятся в assets.
