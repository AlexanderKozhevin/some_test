# edge_center — пространство для роста

Многостраничный дизайн-концепт EdgeЦентр. 24 страницы, интерактивные 3D-модели, продуктовые демонстрации, брендбук и 36-секундное интро. Обновлено 9 сентября 2026 года.

**Сайт:** https://alexanderkozhevin.github.io/some_test/

## Страницы

- Главная с пятью сценариями выбора продуктов.
- 10 продуктов: облако, CDN, защита, S3, Managed Kubernetes, DNS, хостинг, стриминг, QA и управление IT.
- 6 отраслей: онлайн-ритейл, игры, медиа, финтех, образование и SaaS.
- Каталог продуктов, решения, компания, тарифы, блог, разработчикам и контакты.

Полный список маршрутов находится в `site-map.json`. Каждая страница — готовый HTML с относительными ссылками; вложенные адреса открываются напрямую на GitHub Pages.

## Дизайн и взаимодействие

Светлая студийная основа, глубокий синий, бирюза, крупная кириллическая типографика. Металл и стекло объединяют визуальный язык: вычислительные модули, защитные рамки, слои хранения, орбиты доставки и контейнерная архитектура.

- Семь собственных процедурных моделей Three.js на продуктовых и отраслевых страницах. Кнопки разбирают объект на слои и включают вращение. Наведение слегка меняет ракурс.
- Три новые иллюстрации GPT Image 2.5 дополняют исходную скульптуру главной.
- Bento-композиции, локальная подсветка карточек, объёмные миниатюры и анимированные схемы, вдохновлённые приёмами Aceternity. Реализация собственная; исходники платных шаблонов в репозиторий не включены.
- Конфигуратор ресурсов, переключение маршрута CDN, схема фильтрации атак, поиск и фильтр S3-объектов, примеры DNS-записей, слои Kubernetes, чек-лист QA и видеоплеер.
- Общее меню, мобильная навигация, поиск по страницам, фильтры каталога и блога, FAQ и подготовка обращения.

3D останавливает рендер вне экрана и в скрытой вкладке. Учтён `prefers-reduced-motion`; для схем есть явная пауза. Если WebGL недоступен, отображается статическая иллюстрация. Шрифты, иконки, Three.js и изображения загружаются локально.

## Локальный запуск и сборка

Для просмотра готовых файлов достаточно Python 3:

```sh
python3 -m http.server 4317 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4317/. Для редактирования и пересборки необходимы также Node.js и npm:

```sh
npm ci
npm run build
npm run check
```

- `src/content.py` — продуктовый и отраслевой контент.
- `src/build_site.py` — генератор HTML и общей навигации.
- `src/home-original.html`, `src/home-original.js` — основа главной, которую обрабатывает генератор.
- `styles.css`, `site.css` — стили главной и расширенной системы страниц.
- `site.js` — общие взаимодействия и демонстрации.
- `src/three-scenes.js` — исходник 3D; готовый браузерный bundle лежит в `assets/three-scenes.js`.
- `src/check_site.py` — проверка локальных ссылок, якорей, ресурсов, заголовков и идентификаторов всех 24 страниц.

`python3 build_standalone.py` создаёт автономную главную `edge-center-concept.html`: шрифты, стили, JavaScript, иллюстрация и интро встроены. Остальные страницы и PDF открываются на опубликованном сайте. `edge-center-site.zip` содержит весь многостраничный сайт и исходники для локального запуска.

## Контент и границы демонстрации

Продуктовые направления, показатели, контакты и опубликованные тарифы CDN сверены с публичным сайтом EdgeЦентр. Тарифы приведены без НДС; на странице указаны источник и дата. Для других продуктов используется подбор конфигурации без вымышленных цен. Статьи, документация, юридические документы, регистрация и статус сервисов ведут на действующие внешние ресурсы.

Форма проверяет поля и создаёт предпросмотр письма. Пользователь может открыть его в почтовом приложении. Автоматической отправки, CRM, авторизации, платежей и серверного хранения данных в концепте нет. Данные интерактивных примеров вымышлены и помечены как демонстрационные.

Для текста используется Golos Text с кириллицей. Файл оригинальной гарнитуры Edge не был доступен; для точного соответствия утверждённому бренду необходимо заменить `@font-face`. Это презентационный концепт с `noindex,nofollow`, а не официальный рабочий сайт компании.

## Проверка

Все 24 страницы открыты в Chrome на ширинах 1512, 390 и 320 px: горизонтального переполнения страницы нет. Все 16 страниц с WebGL успешно показывают модели. Проверены меню, поиск, фильтры, продуктовые демонстрации, управление 3D, обязательные поля, предпросмотр обращения без отправки, воспроизведение интро и остановка при закрытии. Внутренние ссылки, якоря, ресурсы и синтаксис JavaScript проходят проверки. Отдельное тестирование Safari, Firefox и экранных дикторов не проводилось.

Проверка v2 интро: кадры всех семи сцен и переходов, полное декодирование MP4, длительность и звуковая дорожка. Повторная браузерная проверка воспроизведения для этой ревизии не выполнялась.

## Брендбук и интро

- `downloads/edge-center-brandbook.pdf` — брендбук, 18 страниц: платформа бренда, логотип, цвета, типографика, 3D, UI, тексты и motion.
- `assets/edge-center-intro.mp4` — версия 2, 36 секунд, 1920×1080, 30 fps, H.264 + AAC stereo. Музыка и звуковые детали, без диктора.
- Видеопроизводство v2: 8 новых изображений GPT Image 2.0 (`fal-ai/gpt-image-2/edit`), 6 видеосцен MiniMax H3 Max Turbo, композиция HyperFrames 0.8.32, музыка Lyria 2 из первой версии. Облако, CDN и защита получают отдельные образы и пиктограммы Lucide, собираются в одну систему; отъезд камеры раскрывает масштаб инфраструктуры. Первая версия сохранена в исходном локальном видеопроекте.
